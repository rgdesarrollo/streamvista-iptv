# Contributing to StreamVista

Thanks for helping improve StreamVista. Contributions should preserve the app's TV-first experience and its authorised-content-only scope.

## Before opening a pull request

1. Run `flutter pub get`.
2. Run `dart format --output=none --set-exit-if-changed .`.
3. Run `flutter analyze`.
4. Run `flutter test`.

Keep changes focused and describe the user-visible effect. Do not include provider credentials, private playlists, keystores, Firebase service-account files, generated build output, or release binaries.

## Pull requests

Use a clear title, link related issues, and include screenshots or a short recording for UI changes. Note the platforms and devices you tested.
